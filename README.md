# Lomi Market

Lomi Market is an Expo + React Native customer demo for a premium dark grocery shopping experience. The app showcases onboarding, mock phone verification, product discovery, cart, checkout, order tracking, order history, and profile flows.

## Tech Stack

- Expo
- React Native
- React Navigation
- AsyncStorage
- Expo Vector Icons
- Expo Linear Gradient
- React Native Maps

## Setup

```bash
npm install
npx expo start -c
```

## Data

The app currently uses local mock data only. There is no backend, API integration, or real payment/OTP service in this demo build.

## Demo Flow

1. Splash screen
2. Onboarding
3. Mock phone and OTP login
4. Home product discovery
5. Product details
6. Add to cart
7. Cart and checkout
8. Place mock order
9. Live-style order tracking
10. Orders and profile tabs
