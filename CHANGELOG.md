# Changelog

## 1.0.0 — 2026-07-13

- Added FastAPI/PostgreSQL backend, migrations and deterministic seed data.
- Added OTP/customer and password/admin authentication with rotation, revocation and throttling.
- Added server-authoritative catalog, cart, delivery, promotions, checkout, orders, inventory and audit behavior.
- Added secure local image storage, notification and payment provider abstractions.
- Added responsive React/TypeScript admin dashboard.
- Connected Expo mobile app to real APIs with secure sessions, addresses, COD checkout, persisted cart/orders and localization foundation.
- Added tests, CI, Docker Compose/Nginx deployment, backups and production documentation.
