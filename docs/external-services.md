# External service requirements

- SMS: production adapter credentials, sender identity and approved Palestinian message templates. Development uses a fixed OTP provider.
- Push: Expo/Firebase/Apple push credentials. Device tokens and notification records already exist; development uses a logging provider.
- Maps: Android Google Maps API key and final iOS map configuration for standalone builds. Web/native development uses map preview behavior.
- Payments: provider selection, merchant account, webhook secret and refund policy. COD is fully enabled; online card payment remains disabled.
- Hosting: production domain, VPS/cloud access, DNS, TLS certificate and SMTP/monitoring choices.
- Stores: Apple Developer/App Store Connect and Google Play Console accounts.
- Business: approved legal terms/privacy policy, support contacts, registered business details, delivery policy, final icon/splash review.
