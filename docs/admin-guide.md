# Admin guide

1. Sign in with an administrator account.
2. Dashboard shows order workload, delivered revenue, customers, products and low stock.
3. Categories should be created before products. Products support bilingual content, stock, prices, merchandising flags and optimized images.
4. Orders may move only through allowed fulfillment transitions. Cancelling restocks items; delivered COD orders become paid.
5. Promotions control type, amount, minimum order, maximum discount, schedule and usage limits.
6. Delivery controls service cities, fees, free-delivery threshold, ETA, slots and drivers.
7. Settings store typed JSON groups used by clients and backend calculations.
8. Security lists administrative accounts and protected-change audit records.

Use archive/deactivate actions instead of deleting operational history.
